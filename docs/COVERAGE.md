## Prioritized next increments

1. Add production identity: enterprise SSO, MFA, account recovery and session revocation UI; harden field and department confidentiality.
2. Complete procurement lifecycle: PO revisions/cancellation/returns, invoice exception correction/credits, requisition fulfillment, transactional budget release.
3. Add policy engine: thresholds, multi-step and parallel approvals, delegation/escalation, emergency/single-source controls.
4. Complete master-data administration, secure file finalization/scanning/attachments and vendor bank-change controls.
5. Add import review, historical comparison, extended scoring, full localization and pagination.
6. Implement ERP adapters against actual sandbox credentials and authenticated signed webhook contracts.

Do not describe this release as the complete multinational production system requested in the original specification. It provides a runnable, tested foundation with the main purchasing chain and explicit remaining scope.
